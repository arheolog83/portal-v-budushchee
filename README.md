# Портал в будущее

Конкурсный проект команды «Старт» гимназии №12 Волгограда для хакатона «Идея фикс».

Это минимальная версия веб-приложения для учителей 5–11 классов. В ней доступны два раздела: «ИИ-помощник учителя» для подготовки параметров учебных заданий и «Умное расписание» для ввода недельной нагрузки. Генерация заданий и алгоритм расписания будут подключены на следующих этапах.

## Установка и запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn main:app --reload
```

Для Windows команда активации окружения:

```powershell
.venv\Scripts\activate
```

После запуска откройте в браузере: http://127.0.0.1:8000
