# Как запустить «Портал в будущее» на Windows 10/11

Эта инструкция подходит, даже если вы раньше не работали с Docker. Программа запускается в контейнере — отдельной готовой среде, поэтому устанавливать Python и библиотеки вручную не нужно.

## 1. Что установить заранее

Установите [Docker Desktop для Windows](https://www.docker.com/products/docker-desktop/). После установки запустите Docker Desktop и дождитесь сообщения, что Docker работает.

Git устанавливать не обязательно: проект можно скачать с GitHub как ZIP-архив. Для скачивания и первой сборки нужен интернет.

## 2. Как скачать проект без командной строки

1. Откройте страницу репозитория: <https://github.com/arheolog83/portal-v-budushchee>.
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Откройте папку «Загрузки», нажмите на архив правой кнопкой и выберите **Извлечь всё**.
4. Откройте извлечённую папку `portal-v-budushchee-main`. В ней должен находиться файл `Dockerfile`.

Чтобы открыть PowerShell сразу в нужной папке, щёлкните адресную строку Проводника, введите `powershell` и нажмите Enter.

## 3. Сборка и запуск

Скопируйте в PowerShell команду сборки:

```powershell
docker build -t portal-v-budushchee:latest .
```

Первая сборка может занять несколько минут. После её завершения запустите приложение:

```powershell
docker run --rm -d --name portal-v-budushchee -p 8000:8000 portal-v-budushchee:latest
```

Откройте в браузере: <http://localhost:8000>

Важно: раздел «Умное расписание» работает без дополнительных ключей. Раздел «ИИ-помощник учителя» использует GigaChat и без отдельного ключа покажет ошибку настройки. Не пытайтесь получать, публиковать или пересылать ключи самостоятельно — доступ к ИИ при необходимости настраивает учитель или руководитель проекта.

## 4. Проверка «Умного расписания»

1. Откройте вкладку **Умное расписание**.
2. Выберите **5 дней** и максимум **4 урока в день**.
3. Оставьте две строки или добавьте новые и введите:
   - Математика — 5 уроков, сложность 5;
   - Русский язык — 4 урока, сложность 4;
   - История — 3 урока, сложность 3;
   - Физкультура — 3 урока, сложность 1.
4. Нажмите **Составить расписание**.

Должна появиться таблица с пятью учебными днями. Всего в ней будет 15 уроков, а под таблицей — условная нагрузка каждого дня.

## 5. Как остановить приложение

Выполните в PowerShell:

```powershell
docker stop portal-v-budushchee
```

Контейнер остановится и удалится автоматически. Собранный образ останется на компьютере, поэтому позже приложение можно снова запустить командой из раздела 3 без повторной сборки.

## Частые ошибки

**PowerShell пишет, что команда `docker` не найдена.** Запустите Docker Desktop. Если он уже запущен, закройте и снова откройте PowerShell.

**Сообщение `Cannot connect to the Docker daemon`.** Docker Desktop ещё загружается. Дождитесь состояния «Running» и повторите команду.

**Порт 8000 занят (`port is already allocated`).** Сначала выполните `docker stop portal-v-budushchee`. Если порт занят другой программой, в команде запуска замените только `-p 8000:8000` на `-p 8001:8000`, а затем откройте <http://localhost:8001>.

**Имя контейнера уже используется (`name is already in use`).** Удалите старый контейнер и снова выполните команду запуска:

```powershell
docker rm -f portal-v-budushchee
```

Если сборка остановилась при скачивании файлов, проверьте интернет, перезапустите Docker Desktop и повторите `docker build -t portal-v-budushchee:latest .`.

## Как понять, что всё получилось

- команда `docker ps` показывает контейнер `portal-v-budushchee` со статусом `Up`;
- по адресу <http://localhost:8000> открывается страница «Портал в будущее»;
- кнопка **Составить расписание** выводит таблицу, а не сообщение о следующем этапе разработки.
